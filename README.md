# second_web

HTML, CSS, JavaScript로 만든 정적 웹페이지 실습 프로젝트입니다. 식단 추천 또는 콘텐츠 소개 페이지를 직접 구성하며 프론트엔드 기본기를 연습합니다.

## 프로젝트 개요

`second_web`은 브라우저에서 바로 실행할 수 있는 작은 웹 프로젝트입니다. `second_web/` 폴더 안에 HTML, CSS, JavaScript 파일을 두고 정적 페이지를 구성합니다.

## 주요 내용

- HTML 문서 구조 작성
- CSS 스타일링
- JavaScript 파일 연결
- 정적 웹페이지 실행 방식 학습
- 콘텐츠 소개형 페이지 구성 연습

## 기술 스택

- HTML
- CSS
- JavaScript

## 폴더 구조

```text
.
├── README.md
└── second_web/
    ├── index.html
    ├── style.css
    └── script.js
```

## 실행 방법

별도 설치 과정은 필요하지 않습니다.

1. 저장소를 내려받습니다.
2. `second_web/index.html` 파일을 브라우저에서 엽니다.
3. `style.css`와 `script.js`를 수정하며 화면 변화를 확인합니다.

## 학습 포인트

- 웹 페이지의 기본 파일 분리 방식
- CSS로 화면을 구성하는 방법
- JavaScript로 동작을 추가하는 방법
- 정적 웹 프로젝트를 GitHub 저장소로 관리하는 방법
